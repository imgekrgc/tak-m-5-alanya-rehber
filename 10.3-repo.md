# Adım 10.3 · Kod reposunu açın (Teknik lider)

1. GitHub > New repository
   - Ad: `takim-5-alanya-rehber`
   - Görünürlük: Public
   - "Add a README file" işaretli
   - .gitignore şablonu: Node
2. Settings > Collaborators > Add people: tüm üyeler ve hoca
3. `.gitignore` dosyasının en altına `.env` satırı eklenir (hazır `.gitignore` dosyasında var)
4. Issues sekmesinde her adım ayrı issue olarak açılır ve sorumlusuna atanır (bkz. gorevler/issues-imge.md)

## Dal ve pull request akışı (10.4)
```
git clone https://github.com/<kullanici>/takim-5-alanya-rehber.git
cd takim-5-alanya-rehber
git checkout -b ozellik/giris-ekrani
# değişiklikleri yapın
git add .
git commit -m "Giriş ekranı eklendi"
git push -u origin ozellik/giris-ekrani
```
GitHub'da PR açılır; teknik lider inceler ve `main` dalına birleştirir.
