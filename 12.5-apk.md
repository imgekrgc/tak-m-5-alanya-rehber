# Adım 12.5 · İlk APK (EAS Build) (Teknik lider)

1. `app.json` içindeki `plugins` kısmına kalıcı web adresini yazın:
   ```
   "plugins": [
     ["expo-router", { "origin": "https://<eas-deploy-adresiniz>/" }]
   ]
   ```
2. Derleme ayarını oluşturun:
   ```
   eas build:configure
   ```
   `eas.json` içine APK üreten `preview` profili eklenir (hazır eas.json dosyasında var).
3. Derlemeyi başlatın:
   ```
   eas build -p android --profile preview
   ```

Notlar: Ücretsiz plan ayda 15 Android derlemesi verir; derlemeler sırada bekleyebilir.
Önce web'de test edin, derlemeyi dersten en az bir gün önce başlatın.
Android derlemesini haftada en fazla bir kez yapın.
