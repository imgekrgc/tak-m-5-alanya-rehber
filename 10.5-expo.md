# Adım 10.5 · Expo projesini kurun (Teknik lider)

```
npx create-expo-app@latest uygulama --template default@sdk-58
cd uygulama
npx expo start
```
- Terminalde `w` tuşu uygulamayı tarayıcıda açar.
- API route'lar için `app.json` içinde `"web": { "output": "server" }` olmalıdır (hazır app.json dosyasında var).
- Bundan sonraki tüm dosya yolları `uygulama/` klasörüne göredir.
