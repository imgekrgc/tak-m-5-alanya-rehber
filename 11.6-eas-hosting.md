# Adım 11.6 · Web yayını (EAS Hosting) (Teknik lider)

```
npm install --global eas-cli
eas login
eas env:create --name GEMINI_API_KEY --value <anahtar> --environment production
npx expo export -p web
eas deploy
eas deploy --prod
```
- `eas env:create` görünürlük sorarsa gizli (secret) seçeneğini seçin.
- İlk `eas deploy` deneme adresi, `--prod` kalıcı adresi verir.
- Kalıcı adresi README'ye yazın ve telefondan açıp deneyin.
- Her değişiklikten sonra `export` ve `deploy --prod` tekrarlanır (ücretsiz plan: ayda 100.000 istek).
